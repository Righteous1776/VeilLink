# 续接路由 · 记忆与 Task/Session 协作

当收到“继续 / 断点继续 / 接管”：

1. 使用 Task-ID 查 M02 最近的活动任务摘要、M06 已审核会话总结、M03 决策及 M05 风险；从未授权时不能读其它 Agent 私有任务。
2. 读取 Session 实体与 `HANDOFF.md`、分支 HEAD、真实状态和当前未完成步骤。记忆只提供快速定位，不宣布结果。
3. 对比摘要与实体：一致 → 幂等续接；缺证据 → `NEEDS_VERIFICATION`；发生冲突 → `HOLD` 并申请核验。
4. 恢复上一轮任务而不是重新规划整个项目。只改变证据支持的细节，不变更 Owner 已决定的最高目标。
5. 做完一个可核验动作，更新 Task、工作报告和状态事件；经审核后写 M02/M06。

### 无文件系统平台
输出移动端单文件移交包（Task-ID、baseline、上次证据、下一步、尚未验证部分），由授权者落库。不得将 Chat 内“我会记住”误当持久化成功。
