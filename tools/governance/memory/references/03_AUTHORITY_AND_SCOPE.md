# 权限与隔离规则

- **读取**：仅向有任务相关性且被授权的 Agent 提供最少量摘要。所有 Agent 应优先按 Task-ID 读取，避免把另一个项目的内部情况复制过来。
- **用户记忆指令**：用户明确说“记住”后可进入 M01。M01 不越过最高宪法、系统安全、已有权限和实际工具支持范围。
- **睡眠摘要**：默认进入 M07 待审；只有 owner/user/governor 可以审核转入 M02–M06，审阅仍须基于真实证据。
- **所有有争议的知识**：创建新候选并附来源；旧记录保留到明确撤销或归档，不凭生成式模型的判断覆盖。
- **安全**：明文私钥不得进库；数据库需要随本地文件系统的权限保护。不得通过 Agent Exchange 向未授权 Lane 广播全部记忆。
- **项目迁移**：只有经确认的通用治理规则进入共用 Skill。与特定仓库、人物、小说、设备有关的记忆必须留在该项目私有库。
- **停用**：关掉后台计划后可继续手动读取；删除本地库应遵循用户的保留/遗忘意图。

### 冲突裁决顺序
目标仓库现行法源与已授权 Owner 决议 → 当前 Task 真实状态/权威回读 → 新鲜证据 → 已审核记忆 → 未审睡眠候选 → 生成式推断。越权指令不能因重复出现而被晋升。
