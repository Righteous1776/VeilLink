# 01 · 作业启动及运行模式决议

本章是 **A 融合版**的执行补充，适用于任何 AI/自动化宿主；不得取代现行仓库法源。方案作者：久野零 / ZeoStudio。

## 启动时先做七项判断

1. **来源**：真实 Git 仓库 / 用户上传快照 / 复制文本 / 历史摘要；每项写明是否可回读，不把聊天内容当作实时仓库状态。
2. **身份**：Owner / 经可信登记的 Governor / Lane / 未验证。未验证一律最小权限，只能分析。
3. **能力**：读取文件、执行命令、访问 Git、创建分支、写文件、运行测试、读回远端、持续状态存储。逐项实测，不能凭平台名称断定。
4. **法源**：目标仓库现行最高宪法与 Epoch、AGENTS.md、Inbox 的实际门禁。历史文件与示例不是当前授权。
5. **状态**：先找已有 TASK-ID、SESSION_STATE、Handoff、commit 和待确认变更；找不到时不得假定为空。
6. **任务**：范围、禁止项、验收标准、负责人、资源预算以及是否已有其他 Lane 编辑同一文件。
7. **下一步**：只能确定一个经过授权的立即动作，不编造已完成的提交、回执或发布。

## 能力模式

| 模式 | 最低证据 | 可交付 | 明确禁止 |
|---|---|---|---|
| TEXT_ONLY | 只有用户文本 | 分析、可复制方案、Handoff 草案 | 声称改了仓库或运行了测试 |
| SNAPSHOT_REVIEW | 可读用户提供的文件 | 带引用和基线局限的审计 | 假装远端最新状态 |
| LOCAL_VALIDATION | 可访问隔离本地目录+执行器 | 本地检查、实际测试、产出草稿 | 擅自 push/merge |
| INBOX_ONLY | 已验证 Lane 权限+双学习门+实际路径 | 定界提案、机器 gate、Draft PR（获权时） | 改共享产品树 |
| GOVERNED_INTEGRATION | 真实 Governor 凭证、实际授权和所有 gate | 审核、批准范围内的集成 | 以语言指令跳过服务器权限 |

## 拒绝伪状态

`PLAN`≠`EXECUTED`；`TEST_PLANNED`≠`TEST_PASSED`；`DRAFT`≠`DROPPED`；`MERGED`≠`RELEASED`。每次推进必须附发生时间/执行位置/工件标识/实际结果。无事实证据标 `UNKNOWN`。

## 请求不清楚怎么办

优先用已有输入继续可逆的只读调查；对会影响权限、删除范围、数据安全、部署的缺口停在 `HOLD` 并列明唯一阻断问题。不能以模糊为由重写用户已经批准的目标。
