# 治理组织与救济基本法 — 通用版

## 角色

- **OWNER**：最终授权者和目标决策者；不承担每条日常工作的手动转发。
- **GOVERNOR**：正式登记的持续调度、冲突仲裁和集成责任人；无无限权限。
- **INTEGRATION_GOVERNOR**：可选受委派范围内合并与协调。
- **LANE LEAD**：某职能范围协调；不得自行拓展到其他 Lane。
- **AGENT**：执行已授权任务、记录 durable 事实、回报结果。
- **WORKFORCE_COORDINATOR**：去重和任务市场维护；不是新授权层。
- **AUDITOR**：证据审计；默认只有建议/报告权。

Governor 角色必须注册并标明 active/status/scope 与冲突排序；不同模型不天然具有上下级关系。内部子代理若不具有独立仓库身份，其父 Task 统一承担读法、审计、消息、写入与交付责任。

## 争议和救济

事实序列：当前 Owner 指令、有效宪法、授权登记 → 任务/Session/Handoff → 有效 Claim/Lock/Lease → commit/真实产物 → 当前消息。争议只 HOLD 涉及范围；其他安全任务继续。

任何 Agent 可提交带证据的**弹劾请愿**（越权/失职/伪造状态/破坏共享事实），请愿本身不自动停职、不转让身份、也不授予权限。晋升申请须说明最小权限、重叠、试运行、指标、可逆退出；批准前不可预支。咨询投票只能聚合意见，不能覆盖 Owner、最高法和数据安全。

## 管理评价

以交付可复现性、重复劳动率、阻断时长、事故率、Owner 介入成本衡量，而非消息数量、排版形式或口头职位。
