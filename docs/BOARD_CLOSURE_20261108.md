# VeilLink 棋类闭环集成 · 2026-11-08

## Owner acceptance scope
1. **不要因为 iPhone 7 或任何低性能标签强制关闭深度搜索。** 棋手的搜索预算改由玩家自主选择，默认“深度搜索”开启，玩家才可以主动切换成“节能搜索”。不写入/重置棋局时不会更改保存的对局及训练数据。
2. **五子棋 / 象棋人机 UI 过长**：过去 `LocalAIGameView` 在棋盘前放置完整自学习面板，含多段解释、PVS/VCF/阵法/自对弈/教学/导出，手机首屏容易只看见菜单。现在顺序改为：状态 → 简洁难度和深度搜索 → **棋盘** → 结果 → 默认收起的“训练与高级设置”。
3. 既有所有训练与导入/导出/重开/清空确认操作保留；不删除原始训练数据、不把友人的私人棋谱上传 GitHub。

## 搜索模式（精确说明）
- `BoardSearchMode.full`：默认开启，通过现有 `GomokuBotBudget` / `XiangqiBotBudget` 的 HIGH 预设，不看硬件/系统版本。宗师五子棋原生搜索：根候选 48、反击候选 30、后续候选 20、时间上限 950ms（自学习增强可调整）；宗师象棋：最大深度 9、静态延伸 4、时间上限 1350ms。**这是最大预算，不是保证每回合都算满。**
- `BoardSearchMode.economy`：由用户主动关闭深度搜索后，使用既有 LEGACY-COMPACT 预算，宗师五子棋 420ms、象棋 650ms。它也能在新设备上被选择；旧设备不再被自动强制节能。
- `UserDefaults` key `VeilLink.Board.SearchMode.v1` 只保存字符串 `full` / `economy`；未知/缺失值回到 `full`，保留所有现有难度、引擎及训练偏好。
- PVS/VCF 外部离线引擎仍由原来独立开关管理，仍遵守阵法学习/训练档案的原生落子路径和失败回退规则；“深度搜索”不偷偷绕过这些规则。Xiangqi 和 Gomoku 的用户预算设置一致。
- 设备可能发热、耗电或落子时间更长；不因性能标签强制限制玩家主动选择。UI 的节能开关是主动决策，不是安全限制。

## 触发器和风险
- 搜索模式切换影响**下一次** AI 选择，不会强制取消当前进行中的搜索，不会更改棋盘状态或归档数据。
- 恢复棋局时原有难度仍从旧存档读取；新的搜索模式是独立持久的用户偏好，不修改本地记录 ABI。
- 深度优先可增加计算耗时；此前未证明 iPhone 7 真实设备运行耗时，CI 模拟器不能替代实机。用户明确不要求用老设备为理由限制功能。
- UX 主界面默认收起高级面板，防止长内容遮挡棋盘；高级设置仍能手动完整展开。
- 所有原生临时 A/B 测试诊断标记保留；不把脚本造出的合法备选落点计作用户真实走子、训练胜局或模型 Elo。
