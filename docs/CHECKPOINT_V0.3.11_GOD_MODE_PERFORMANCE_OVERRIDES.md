# V0.3.11 God Mode Performance Overrides

This checkpoint adds a local-only developer performance switchboard inside authenticated Owner Mode. Automatic device profiles remain the default. When explicitly armed, the owner can individually override high-definition image previews, outbound attachment cache size, message refresh coalescing, full visual effects, and persistent animations. A one-tap chaos preset enables all five; “restore sanity” returns to the automatic device policy and clears transient caches.

The override layer never changes Protocol 4, Schema V8, cryptographic domains, BLE wire limits, message encoding, attachment chunk size, or peer compatibility. High-resolution preview changes only the local display thumbnail. Expanded attachment cache remains memory-only. SE1/iPhone 7 compatibility reductions stay active unless the corresponding visual override is deliberately enabled.
