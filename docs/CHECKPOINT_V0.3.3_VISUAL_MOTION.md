# V0.3.3 Visual & Motion Polish

## Scope
UI and motion-only checkpoint. No feature expansion, no Protocol change, no Schema change.

## Visual system
- Reworked the palette from flat black/gold into layered obsidian surfaces with restrained warm metallic highlights.
- Added reusable ambient background, glass surface, premium card, icon-disc and press-feedback primitives.
- Added globally coordinated dark navigation/tab chrome for iOS 15+.

## Conversations
- Conversation rows now use elevated cards, subtle identity rings and compact encrypted-state metadata.
- Message bubbles use metallic outgoing surfaces and layered incoming surfaces with restrained depth.
- Composer, search and reply preview use a consistent floating-glass treatment.
- Send/add controls use compact circular hardware-like affordances and press micro-interactions.
- Message insertion, reply/search appearance and button feedback use short state-driven motion while respecting Reduce Motion.

## Nearby
- Replaced the static status ring with a quiet radar visual.
- Pulse animation only runs while Bluetooth scanning is active and stops for Reduce Motion.
- Peer trust states use compact semantic badges instead of raw colored text.

## Lock / onboarding / transfer
- Lock screen keypad and identity entry were visually aligned with the same design language.
- Onboarding now uses a custom geometric Veil mark, glass identity form, premium primary action and clearer product hierarchy.
- Transfer shards keep the real checkpoint-driven animation, with a subtler directional field, edge treatment and progress spine.

## Compatibility
- Version: 0.3.3 build 9
- Minimum iOS: 15.0
- Protocol: 4 (unchanged)
- Schema: V7 (unchanged)
- No new persistence migration.
