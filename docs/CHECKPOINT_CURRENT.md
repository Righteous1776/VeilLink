# Current checkpoint

V0.3.13 BLE Reliability Overhaul, cumulative from GitHub main `aadb80b02e2fc4eeab3d4032d392cd37267e82fc`. Protocol 4 and SQLite Schema V8 remain unchanged. The BLE transport now uses RSSI-smoothed adaptive packet pacing, control-packet priority, persistent capped reconnect instead of a five-attempt stop, connected-link RSSI polling, compact advertising, stalled-queue recovery, repeated idempotent Hello delivery, reconnect-triggered outbox wake-up, and application retries that continue until the persistent outbox expiry rather than failing after ten accepted sends. This improves eventual delivery on marginal links without claiming a physically guaranteed meter range.
