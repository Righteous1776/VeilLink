# Veilopoly 离线实时股票系统 / 2026-11-07

## 交付范围

本系统只模拟游戏内虚拟股票，不连接互联网、真实证券、账户、支付或下注。行情、订单和持仓都进入 `GameState` 的银行账本，可编码、哈希和重放。iOS 展示层每 2 秒提交一次明确的 `.stockTick` move；时间只负责调度，价格仍由种子和 tick 计算。

五支虚构股票：VTL 维尔交通、AUR 极光能源、MNT 薄荷港湾、NOV 新星工坊、ORB 轨道系统。每支股票有不同基准价格、波动率和长期漂移。

## 行情模型

每个 tick 将以下整数因素相加为基点变动：

- 全市场共同因子；
- 股票自身波动；
- 牛熊状态（-2…2，每 24 tick 可切换）；
- 向基准估值的温和均值回归；
- 低概率、双向的局部事件冲击。

单次变化不超过 9%，每 60 tick 建立新模拟交易日。相对当日开盘价的上下限为 ±10%，触及后暂停两个 tick。走势图最多保存最近 96 点，避免长局无限增长。成交量与绝对波动相关，但不冒充真实盘口。

市场拥有独立的 RNG counter，刷新行情不会改变骰子、卡牌或现有金融结算随机序列。同种子、同 moves 产生逐字节一致的行情与状态哈希。

## 交易规则

- 整股交易，每笔 1…10,000 股，单一持仓上限 100,000 股。
- 买卖手续费 0.50%，最低 1 游戏币。
- 买入使用加权平均成本；卖出记录已实现盈亏。
- 行情暂停期间不能下单；余额不足、超卖或未知代码不改变状态。
- 债务清算先取可用存款，再按代码顺序卖出未停牌股票，最后才进入原有地产处置。
- 破产时剩余股票按最后报价计入清算财产；结算排名的净资产也包含股票市值。

旧存档中的银行账本没有 `market` 字段时仍可解码，首次行情或订单操作才建立市场。

## UI/UE

银行面板新增实时行情区：股票选择、当前价、涨跌幅、开高低、成交量、牛熊状态、停牌提示、60 点渐变折线图、股数 Stepper、买入/卖出、持仓成本、市值和盈亏。动态数据由程序绘制，不烘焙进 Astra PNG。

折线图使用 SwiftUI Canvas 的轻量实现，参考常见金融图表的分层方式（网格、面积、价格线），不引入网络或第三方二进制依赖，保证离线构建和资源可审计。

### 交易终端 V2

- 独立 `VeilopolyStockMarketPanel` 采用深蓝灰、克制金色描边和玻璃层次，与 Astra HUD、Kimi 棋盘保持职责隔离；没有替换或复制二者素材。
- 五标的横向行情带带有迷你走势、涨跌符号和停牌状态；主图同时绘制价格、面积、成交量、昨收参考线和最新点。
- 买入/卖出切换、1/5/10/100 快捷股数、Stepper 和“最大”数量均为真实交互。订单区展示成交额、手续费、预计支出/到账以及引擎现价。
- UI 订单预览与 reducer 共用 `StockTradeEstimate`，最大可买使用精确二分计算，因此不会出现界面金额与实际扣款舍入不一致。
- 持仓区汇总市值、浮动盈亏、已实现盈亏；逐标的显示股数、成本、现价和盈亏，点击持仓可切换主行情。
- 买卖成功使用轻触反馈，失败使用错误触感；涨跌同时显示正负号和数值，不只依赖红绿颜色。中国金融配色为上涨暖红、下跌薄荷绿。
- 终端位于既有可滚动操作抽屉内，提交按钮保持至少 44pt 高；顶部 More/Exit 和底部操作入口的最新分离规则未改变。

## 验证边界

### V3 交互与刷新修正（2026-11-07）

- 长按走势图 0.25 秒后拖动，显示十字参考线、对应 tick 的价格和成交量；VoiceOver 可用调整动作逐点读取。选择点仅控制查价，不影响成交价格。
- 本局手动订单成功后，从 reducer 的结构化 Effect 生成成交回执，保存最近 40 条，终端按当前玩家显示最近 8 条；重开清空。回执是会话内 UI 数据，不伪装为持久化账单，不包括自动偿债卖股。
- 订单禁用原因同时覆盖含手续费余额不足、超卖、暂停交易、单笔股数与现金上限；零可买/可卖时“最大”显示 0。上一笔订单错误保持显示，下一笔成功后清除。
- 价格 tick 仅更新 GameState，不重新调用 SpriteKit 的棋盘 display，也不清空订单反馈。前台 scenePhase 才调度 2 秒行情任务；进入后台、离开页面或任务取消立即退出，恢复后重新等待 2 秒，不补跑后台行情。
- 价格及持仓折叠动画尊重 Reduce Motion。真机触摸、后台生命周期和 Apple SDK 类型检查仍待验收。
- Swift 6.2.1/Linux：股票与终端状态专项 **15/15 PASS**；全量 **134/134 PASS**；ARM64 iOS 16 frontend parse PASS（仅语法）。新增测试验证含手续费余额、卖出现金上限、真实成交回执过滤和查价坐标边界。

新增 Engine 测试覆盖：2,000 tick 确定性与价格边界、独立 RNG、费用/平均成本/盈亏、reducer 结构化事件、失败原子性、停牌、债务自动卖股、旧账本兼容。
