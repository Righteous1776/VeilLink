# VeilLink 大富翁 · 游戏设计文档（GDD v1）

> 项目代号：**Veilopoly**。四人回合制强手棋（Monopoly-like），运行于 VeilLink iOS 客户端，
> 支持单机（AI 补位）与联机（VeilLink 加密消息通道）。2D/2.5D 呈现。
> 本文档与 `MODELING_SPEC.md`（逻辑建模）、`RENDERING_SPEC.md`（渲染规格）配套，
> 供 ChatGPT 编码与我方建模/渲染对齐使用。

---

## 1. 设计目标

| 目标 | 说明 |
|---|---|
| 四人局 | 真人 1–4 人，不足 4 人由 AI 玩家补位（单机与联机同一规则引擎） |
| 单机/联机统一 | 同一套确定性规则引擎；联机 = 引擎 + 事件广播，单机 = 引擎 + 本地 AI 生成 move |
| 复杂操作 | 完整支持：买地、拍卖、玩家间交易、抵押/赎回、建造升级、卡牌效果、坐牢三途径 |
| VeilLink 集成 | 游戏消息走 VeilLink 应用层消息通道（端到端加密继承 VeilLink 传输），**不改动 Protocol 4 / VLGM1 v1 / 传输保护面** |
| 时长控制 | 单局 20–60 分钟：初始资金 ¥1500、地产租金梯度、可选「快速破产规则」 |

## 3. 核心规则

### 3.1 回合流程（阶段机）
`ROLL → MOVE_ANIM → TILE_RESOLVE → [BUY|AUCTION] → MANAGE（建造/交易/抵押） → END`

1. **ROLL**：玩家点骰（或 AI 自动）。 doubles（同点）重掷一次；连续三次 doubles → 入狱。
2. **MOVE_ANIM**：按点数逐格前进（渲染逐格弹跳）。
3. **TILE_RESOLVE**：按落点结算：
   - 无主地产：选择 **购买**（标价）或进入 **拍卖**（全员竞价，起拍 ¥1，轮流加价或弃；AI 按估值参与）。
   - 有主地产：付租金；若地块带全套色组且持有旅馆，租金 ×…（按标准梯度）。租金可触发**破产清算**。
   - 机会/命运：抽卡并执行（卡牌池见 3.3）。
   - 税：直接扣款，¥200/¥100。
   - Go To Jail：移送 Jail，回合结束。
   - Jail（30 格玩家落 10 不触发任何事）。
4. **MANAGE**（仅限自己回合内）：建造（房屋 ¥50–200 按色组、旅馆 = 4 房 + 升级费）、出售建筑（半价回收）、抵押地产（得标价一半）、赎回（付一半 + 10% 利息）、发起**交易**。
5. **END**：过回合；doubles 则回到 ROLL。

### 3.2 交易（玩家 ↔ 玩家 / AI）
交易面板支持任意组合：现金、地产（可含抵押标记）、自由卡（Get Out of Jail Free）。
- 双方确认后原子结算；联机时交易提案作为 move 广播，对方接受即生效。
- 已抵押地产可交易，债务随交易转移。

### 3.3 卡牌池（每池 16 张，可配置）
- **机会 Chance**：前进到最近铁路/公用事业并买或付双倍租金、前进到某地产、后退 3 格、直接入狱、出狱卡、罚款/奖励（±¥50–150）、去 GO 等。
- **命运 Community Chest**：以金钱收付为主（医院 ¥100、退税 ¥150、生日每人 ¥50、修理费每房 ¥25 每旅馆 ¥100 等）+ 出狱卡 + 去 Jail。
- 卡牌效果统一建模为 `Effect` 结构（见 MODELING_SPEC §5），新卡只需配置不写代码。

### 3.4 破产与胜利
- 现金不足支付时进入**清算链**：自动触发抵押 → 卖建筑 → 放弃交易谈判；仍不足即破产。
- 破产玩家资产移交债权人（银行或特定玩家）；全员资产归一人或达成协议时结束。
- 结局画面：排名 + 资产明细 + 「再来一局 / 返回聊天」。

### 3.5 坐牢三途径与出狱三方式
入狱：落 Go To Jail（30）、连续三次 doubles、抽「入狱卡」。
出狱：① 付 ¥50 保释（下回合可掷）；② 掷 doubles 出狱并可行动；③ 使用出狱卡。第 3 回合仍坐牢强制付 ¥50。

## 4. AI 玩家

统一规则引擎，AI = move 生成器（详见 MODELING_SPEC §7）。三档策略：
- **保守**：优先凑齐色组才买地，交易倾向低风险；
- **均衡**：按地块估值期望值买地（地价 / 租金回本回合数 < 阈值）；
- **激进**：高频交易、快速建造压低对手现金。

联机时真人不足由房主端跑 AI move（确定性，各端重放一致）。

## 5. 与 VeilLink 的关系（治理边界）

- 游戏入口：聊天会话内「发起游戏」→ 应用层游戏会话（GameSession），与既有聊天消息并列呈现。
- 联机载体：**新增应用层消息类型**（如 `vl-game-move`），复用 VeilLink E2E 加密通道；不改 Protocol 4、VLGM1 v1、SQLite Schema V8、A9/A10 门禁。
