## 设计统一规则
- 机会＝探索、邀约、城市变数；命运＝账本、人生事件、税务与赠与。两者都用象牙纸纹、古金压印边框、深青绿高对比正文。
- 牌面上方优先显示「机会 / 命运」，中央是标题及短叙述，下方明确标注「执行结果」。不要把剧情描述误当经济结算，不嵌入固定玩家姓名或持仓。
- 支付、收取、修理、移动、出狱卡等文本与 SampleCards 保持一致。临时股票分红/出售奖励只是银行现金，不改现实模拟股票仓位；文案对此有明确限制。
- 32 个 stable text ID 与游戏内部 0–31 牌 ID 一一对应。新的一套效果规则必须先更新安全匹配，不允许继续展示过期裁定。
- 旧中文 UI 的「宝箱」标题与棋盘「命运」不一致，应统一视觉标为「命运」，底层编码 `.chest` 不变。
- 配套 iOS15 SwiftUI 动态排版使用滚动容器，确保长短文本仍可读，卡面图片复用已入库的 ivoryR1ChanceCard / ivoryR1ChestCard，保持与主棋盘一致。
