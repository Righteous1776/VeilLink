# Veilopoly 象牙白城市文书 R1 · 六类实装

**任务**：`VL-VEILOPOLY-IVORY-CIVIC-R1-20261107`。
**集成基线**：`e62ffc135f9c2444629fe0ae8d20ce206518dc96`（`dev/veilopoly`），最低 iOS 15。
**风格**：唯一象牙白主视觉、古金内边框、深青绿文字；保留现有 Astra 功能按钮和 Kimi/Codex 棋盘。

| 文书 | 触发入口 | 真实数据字段 | 限制 |
|---|---|---|---|
| 地契登记簿 | 地产管理选择产权 | 编号、名称、产权类别、登记价格、持有人、建筑、抵押 | 特殊地块不展示虚假地契 |
| 公开竞价公告 | 拍卖状态 | 标的、真实最高出价与出价人、下一竞价者、剩余竞价人数 | 未成交前绝不写已售 |
| 产权交换协议 | 已提交交易谈判 | 甲乙双方、各自现金、地产、机会/命运出狱卡 | 显示待决议，不伪装已完成 |
| 银号往来存根 | 银行管理 | 玩家现金、存款本金、待偿贷款、投资本金、期数 | 各项分别记录，不误加作现金 |
| 债务清算通知 | 债务阶段 | 债务人、待付款、现有现金、债权人 | 不能提前宣告破产 |
| 终局结算公报 | 胜负已经判定 | 胜者、其现金、产权数、破产人数、行动编号 | 不与净资产排名混淆 |

**一致性**：六类文书都由 `VeilopolyCivicText` **只读**生成，绑定 `GameState`；不会新增或修改任何规则动作、序列、随机数、牌组、资产账本、存档格式或联机哈希。SwiftUI `VeilopolyCivicDocumentPanel` 作为**同一**象牙白文书组件嵌入原有 Astra 操作抽屉；没有新的常驻侧栏、浮层或遮挡触控。已有 Codex 面板保留不替换。

**测试源码**：`CivicTextTests.swift` 提供 6 项引擎状态、金额、所有权、隔离及纯读检查。`VeilopolyCivicDocumentPanel` 仍需 Xcode iOS15 编译和 iPhone7 横屏/动态字体/长篇内容验收。不得把未运行的 XCTest 写成 PASS。

**后续**：正式版存档续局、UI 面板、拍卖/交易、资产核算的真机回归。未授权修改 `main` 或 IPA。
