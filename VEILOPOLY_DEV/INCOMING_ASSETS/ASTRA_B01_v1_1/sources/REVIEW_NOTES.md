# B01 v1.1 验收边界

导出验证以本包 `VALIDATION.md` 的实际运行结果为准：由 package_and_verify.py 检查完整性、尺寸、SVG text 隔离、alpha 通道、声明的命中尺寸以及右侧布局边界。命中尺寸检查只验证坐标数据，不能替代真实触控测试。v1 的成图检查不自动视为 v1.1 验收。

未做：游戏内运行、设备安全区、Dynamic Type实测、真实Kimi场景与UI色彩组合、VoiceOver事件、键盘交互实测。它们由ChatGPT集成验收。

集成限制：继承自 v1 的带图标九宫格皮肤仅支持原始高度下横向伸缩，不能纵向非等比拉伸图标；需要改变高度时重排 SVG 或拆分图标覆盖层。新增详细纸卡均 aspectFit，不能拉伸雕刻纹样。此限制不由边距数值校验自动证明，必须按接入说明执行。

视觉定位：深蓝灰/青金属/香槟金仍作为结构框架，参考图修订增加奶油纸底、雕刻票券边框与地产分组色带；依靠层级与留白，不使用大面积强光晕。按钮、图标和票券为原创可编辑矢量；不复制参考字标和角色，静态反馈不冒充 B02 动画。精密城市参考不等于本包提供城市模型。

画面里的KIMI棋盘线框只显示预留区域，不能交付为完整场景美术。三种银行产品共用受限模板，收益/利率都未写死。5份纵向640pt源稿是右侧可滚动面板展开图，整体游戏预览始终为横屏，不是竖屏游戏布局。
