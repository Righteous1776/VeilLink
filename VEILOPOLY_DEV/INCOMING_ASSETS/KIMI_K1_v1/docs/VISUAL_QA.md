# VISUAL_QA · K1 视觉质量基线（v1.0，2026-11-06）

## 1. 色组对比度（格底色 #F8FAFC 上的色条文字）

| 色组 | colorHex | 用途 | 评级 |
|---|---|---|---|
| brown | #8B5E34 | 色条/标记 | ✅ ≥4.5:1（白字） |
| lightblue | #AAD8E6 | 色条 | ⚠️ 3.0:1——色条上不放文字，文字走深色 |
| pink | #D93A96 | 色条/标记 | ✅ |
| orange | #F7922E | 色条 | ⚠️ 2.9:1——色条上文字用深棕 #4A2C0A |
| red | #ED1B24 | 色条/标记 | ✅ |
| yellow | #FEF200 | 色条 | ⚠️ 1.2:1——色条上文字用深灰 #333 |
| green | #1FB25A | 色条/标记 | ✅ |
| darkblue | #0036AB | 色条/标记 | ✅ |

规则：色条一律不放白色文字；黄/浅蓝色条上的必要文字用深色反白。

## 3. 可访问性

- Dynamic Type：面板文字支持到 .xxxLarge；棋盘格内名称超限时省略为「色组+价格」。
- VoiceOver：每格可读「第 N 格，名称，归属玩家，租金 X，N 房」；token 可聚焦并播报玩家与位置。
- 色弱：色组除颜色外有形状差异（房屋数/图标数），交易面板资产列表带文字标签——不纯靠色。
