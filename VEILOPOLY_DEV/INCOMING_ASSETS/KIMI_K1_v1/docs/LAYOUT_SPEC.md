# LAYOUT_SPEC · K1 视觉接口冻结（v1.0，2026-11-06）

> 与 `SPRITE_MAP.json`、`ASSET_MANIFEST.json` 配套；坐标基于 `model/board.json`（40 格）与
> `model/layout-projection.json`（含 15° 倾角投影）。**不改 Move/Effect/GameState 与 Swift 引擎接口。**

## 1. 设计基准

| 项 | 值 |
|---|---|
| 逻辑单位 | 24u 棋盘网格，边格 2×3u、角格 3×3u（board.json layout） |
| 设计基准宽 | 1080pt（iPhone 竖屏棋盘适配宽度；iPad 等比放大） |
| 换算 | `scale = 棋盘显示宽度pt / 24` |
| 倾角 | 15°（规格允许 12–15°，K1 固定 15） |
| 投影 | `sx = u·scale`；`sy = (v·cos15° − h·sin15°)·scale`（h=离地高度） |
| token 站立高 | h = 0.45u（约 20pt @1080 基准） |
| 帧率/主题 | 60fps 目标；暗色「夜色玻璃」为主主题，浅色「日间毛毡」备选 |

## 2. 格子坐标（逻辑 → 屏幕）

每格 rect 由 board.json `layout {side,x,y,w,h}` 给出；渲染三步：
1. 中心 `(cx, cy) = (x + w/2, y + h/2)`（逻辑坐标，y 向上）
2. 投影 `project(cx, cy)` 得棋盘内屏幕点（棋盘锚点 + 缩放）
3. token 锚点用 `project(cx, cy, h=0.45)`——底部贴格、顶部随倾角后移

**房屋槽位**（L2 层，相对格中心偏移，单位 u）：
`houseSlots = [(+0.45,+0.30), (−0.45,+0.30), (+0.45,−0.30), (−0.45,−0.30)]`，1–4 房按序填充；旅馆居中（1 个，替代 4 房）。偏移量与方向无关（四边通用），如需贴边旋转由工程侧按 `side` 微调 ±0.05u 以内。

**同格多 token 扇形**：进入已占用格时，同格 token 按 `(idx − (n−1)/2) × 28°` 绕格中心散开，半径 0.55u，0.2s spring。

## 3. iPhone 竖屏主版（390×844pt 参考系）

```
┌──────────────────────────┐
│  状态栏/导航 44           │
│  回合横幅        h=56     │ ← 滑入式（TurnInfo + 当前玩家色点）
│  ┌────────────────────┐  │
│  │                    │  │
│  │   棋盘（正方形）     │  │ 边长 = 390 − 2×12 内边距
│  │   15° 倾角全景      │  │ 远排 0.94× 近排 1.0×
│  │   骰子落点=中央区    │  │
│  │                    │  │
│  └────────────────────┘  │
│  玩家条 P1–P4  h=64      │ ← 现金/坐牢标记/色点；当前玩家高亮描边
│  操作面板区     h≈200     │ ← BUY/AUCTION/MANAGE 按钮与弹窗锚点
│  主安全区 home indicator  │
└──────────────────────────┘
```
- 触摸命中：格子热区 = 格 rect 外扩 4pt；管理面板按钮 ≥44pt。
- 竖屏限制：交易面板/卡牌详情以全屏 sheet 呈现（不挤压棋盘）。
- 可读性优先：棋盘文字（名称/价格）最小 9pt @2x 等效。

## 4. iPad 横屏适配（1180×820 参考系）

```
┌───────────────────────────────────────┐
│ 棋盘区（左）          │ 侧栏 340pt      │
│ 820×820 正方形棋盘     │ ┌───────────┐ │
│ 倾角/投影与 iPhone 同 │ │ 回合横幅   │ │
│ 比例规则，scale×1.7    │ │ 玩家列表   │ │
│                      │ │ 操作面板   │ │
│                      │ │ 交易/建造   │ │
│                      │ │ 都放此栏    │ │
│                      │ └───────────┘ │
└───────────────────────────────────────┘
```
- iPad 不放大 token 文字（防糊）：棋子 displaySize ×1.35（SPRITE_MAP 已标），格子文字保持与 iPhone 同 pt 值。
- 分屏/悬浮窗（Slide Over）下退化为 iPhone 竖屏布局。

## 5. 渲染层级与 zPosition

见 SPRITE_MAP.json `layers`（L0=0 … L7=70）。L4 token 层内按 token 的 `project().y` 动态重排 z，保证走近排时正确遮挡（规格 §1「层叠深度」）。

## 6. 主题色（夜色玻璃 · 冻结值）

| 用途 | 暗色 | 浅色 |

| 桌布 L0 | #0B1220 | #F5F0E6 |

## 7. 与引擎的边界

本规格只定义「视觉接口」：坐标、层级、尺寸、主题。Phase/ViewCommand 语义不变（A11：渲染 ACK 交 coordinator，由 ChatGPT 实现）。
