# Submission Root

Create submissions only below:

`AGENT_INBOX/submissions/<agent-id>/<task-id>/`

Do not edit another agent's directory.

Copy the structure from `../_template/`.

When complete, report an `[AGENT-DROP]` block and stop.


## Asset Drop

Binary art/model resources are allowed only for agents listed with an active grant in `../ASSET_GRANTS.json`. Granted payloads go under the submission's `ASSETS/` directory and require `ASSET_MANIFEST.json`. See `../06_ASSET_DROP_POLICY.md`.
