## 本轮修复

1. ChatView 的“发送游戏邀请”菜单加入大富翁；聊天 MiniGameHubView 加入当前联系人的联机面板。
2. 聊天区出现临时邀请/接受/继续状态卡，放在消息滚动区之外，不写 SQLite、不抢消息锚点。
3. 展示 context 将聊天、聊天游戏面板、独立大厅绑定到同一个 room model，避免多个入口同时弹全屏。
4. 新联机房间显式采用与单机相同的 V5 工厂、卡牌、金融与价格；旧 room JSON 缺少 rulesVersion 时仍经典。
5. 新配置的邀请使用应用 packet v2，阻止旧客户端静默按经典规则开局；现有加密通道和 Wire v4 保持。
6. 单次邀请意图可等待安全链路恢复，120s 内无需二次点击；不在定时器反复重置聊天密钥。
7. 忙碌/不支持控制消息的情况可见报错；只有提交传输后才显示已提交，而不声称送达。
8. App 前后台同步房间生命周期，无需先打开独立游戏大厅才能接收邀请。
