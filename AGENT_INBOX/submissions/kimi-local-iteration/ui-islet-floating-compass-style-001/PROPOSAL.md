# PROPOSAL — 浮屿（Islet）：第五种界面风格

## 任务来源

Zeo：「根据你的审美来做你的 UI，都可以大改。你甚至可以以另一种方式来呈现底部栏，不要局限于传统聊天软件的布局，按键布局等都可以改变，让它更有现代的设计感。」

## 设计：浮屿

深海为底，万物浮起。三个决定：

- **深海极光底**：靛海之上一团金（左上）、一团极光青（右下）、一团月晕（中顶），径向微光不抢内容，只给深度。昼间为雾珠浅海，同一结构。
- **内容即浮岛**：卡片改为 20–24pt 连续圆角岛面，0.5pt 极光发丝描边 + 大半径悬浮投影；按压时不熄暗、反而点亮（brightness +0.045 并泛起金光晕）——浮岛被「按亮」，不是被「按瘪」。
- **导航换一种存在方式**：废除常驻底栏。收缩为一枚悬浮**罗经胶囊**（safeAreaInset 停靠底部中央）：当前分区图标 + 名称 + 未读微记 + 展开箭头。点按以弹簧动效向上展开**浮岛选单**——52pt 大行、17pt 编辑排版、圆形图标章、选中项金晕 + 勾选；点空白或选定即合。导航从「占地的基础设施」变成「随叫随到的罗盘」。

## 与白描的关系

白描是「减到只剩文字」，浮屿是「让内容有重量地浮着」——同一架构（调色板 + 分支 + 独立根容器）上的两种极端，互补不冲突。浮屿为普通样式，直接出现在主题列表第 4 位，无需授权闸门。

## 变更摘要（4 文件，+307/−6）

1. `AppearanceTheme.swift`：`case islet`、标题/副标题/预览、`isIslet`、`ISLET` 标签、昼夜双调色板（夜：深海靛 + 琥珀金 + 极光青发丝；昼：雾珠浅海同构）。
2. `AppTheme.swift`：三条渐变浮屿分支；`VeilAmbientBackground` 接入 `VeilIsletBackground`；`VeilCardModifier` 浮岛卡（岛面 + 微光描边 + 悬浮投影）；`VeilPressStyle` 浮屿按压（轻缩 0.975、点亮 +0.045、金光晕半径 12）。
3. `IsletRootView.swift`（新增）：`VeilIsletBackground` + `VeilIsletRootView`（内容复用五分区视图与遥测 + 罗经胶囊 + 浮岛选单，`navigation.tab` 遥测附 `chrome: islet`）。
4. `AdaptiveRootView.swift`：根容器浮屿分支（白描分支之后）。

## 兼容性

- 其余四种风格逐像素不变（全部逻辑在 `isIslet` 分支内）。
- 持久化复用 `appearance.theme.selection.v1`；旧版本读到 `islet` 原始值落既有缺省回退（veilOriginal），可安全降回。
- iPhone/iPad/深浅色统一浮屿框架；选单展开态有 VoiceOver 标签与 `.isSelected` 特质。
