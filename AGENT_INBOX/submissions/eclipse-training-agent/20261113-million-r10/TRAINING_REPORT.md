# ECLIPSE R10 实际交付报告

已实际训练并运行ECLIPSE候选，未改学习计数。最终模型在 **1,848,616条完整D4棋盘＋动作联合去重记录**上拟合；另外留出120,343条验证、220,532条测试。来源为两份Owner真实棋谱与校验过的原生种子。它们是实际棋谱局面的反事实候选训练样本，**不是百万盘棋或百万独立棋盘**。
