# Risks / overlap
- Scope: INBOX_ONLY. Do not apply to main or trigger signing, IPA, release, workflows, schema migrations, source-tree edits.
- The code scan may reject an externally winning move not proven by one/two-ply geometry; native fallback is the safety response; benchmark counterattack and latency.
- Some recorded wins may be resignations; 5 completed result labels have no final five-in-a-row under simple freestyle geometry.
- Actor separation is not reliable in the old PositionStat: a single board hash can be played by human or AI due to seat switching. Requires separately reviewed migration.
- Learning rewards and exact history prefixes can be too weak to reverse a bad tactical root choice.
- Offline replay validation does not establish production iOS compile/XCTest pass.
- Existing submissions overlap game controller and R4/R6/R8 heuristics; Governor must adjudicate before integration.
- Training-package JSON cannot safely be imported directly using V29's destructive import semantics.
