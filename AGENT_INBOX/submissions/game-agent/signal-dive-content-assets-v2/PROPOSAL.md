# Signal Dive / 深潜信号 — Content + Assets V2

V2 adds a fourth sonar category: biological schools. These contacts are deterministic by seed and segment, so the visual fish layer does not invent random positions separate from the gameplay sensor model.

The scene reads biological contacts from the rule core, places schools from contact distance/bearing, and uses the staged Kenney Fish Pack PNGs through stable aliases. If those images are unavailable, procedural fish silhouettes preserve gameplay and rendering.

Reduce Motion reduces suspended-particle density and suppresses impact camera shake without changing simulation state.

Three CC0 Kenney Fish Pack PNGs are staged as direct runtime art assets. The earlier deep-sea fog, Bloom floodlight, beacon, massive-unknown and sonar systems remain intact.

No protocol/schema/storage/workflow/version/release or product-tree mutation is proposed.
