# Risks

- Rainline V1 intentionally overlaps and should be superseded rather than merged together with V2.
- OBJ files expect local MTL filenames; integration must preserve pairing or rewrite references.
- The staged MTL files are deliberate CC0 derivatives with flat fallback colors, not Kenney's original colormap.
- Direct 3D runtime rendering is optional; offline bake/atlas is preferable for predictable SpriteKit performance.
- Four fault classes require balance passes across multiple seeds.
- Shared Game Lab navigation/render-policy adjacency remains for Governor arbitration.
