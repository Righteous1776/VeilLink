# Risks

- 12-node topology increases balancing complexity and may make late-game cascades too harsh.
- Three GLBs are source models, not direct SpriteKit textures; integration requires controlled offline sprite baking or a separate 3D rendering decision.
- ShaderKit MIT notice must remain with copied source.
- Wider iPad camera could expose sparse edges of the procedural map and needs visual smoke testing.
- This successor overlaps Draft PR #30 by design and should replace, not combine with, that older Blackout drop.
- Shared navigation remains Governor-owned.
