# PROPOSAL — 会话工作台 + 消息锻造台

## 产品目标

VeilLink 已有搜索、引用回复、图片/语音、置顶和本地删除，但长对话仍只能从头翻找，发送前也缺少结构、字节预算与泄密防护。会话工作台把聊天从“消息流”提升为可使用的本地信息空间；消息锻造台把临时草稿变成可检查、可预览、由用户决定是否回填的消息。

## 功能

1. **会话概览**：消息总数、收发数量、活跃天数、行动项、问题和资料数量。
2. **行动项**：识别 `待办`、`记得`、`别忘`、`请`、`需要`、`安排`、`TODO`、`[ ]` 等明确前缀。
3. **待回答问题**：识别中英文问号和常见中文疑问开头。
4. **链接资料库**：从正文与新回复中提取 HTTP(S) 链接，清除尾随标点；长按可复制到仅限本机、5 分钟过期的剪贴板。
5. **附件索引**：图片、语音和其他附件显示类型、大小及收发方向。
6. **组合筛选**：类别与关键字同时过滤。
7. **回到原消息**：条目点击后关闭工作台，并由现有 `ScrollViewReader` 跳转到对应气泡。
8. **后台全历史分析**：打开工作台时在后台读取完整本地历史，不受正常聊天窗口分页限制；新消息到达时更新工作台。

## 消息锻造台

1. **五类结构模板**：进展同步、明确请求、会议约定、待办清单和问题报告。
2. **四种表达样式**：原文、紧凑、要点与礼貌请求；转换确定、可预览，不调用云端模型。
3. **真实协议预算**：按 UTF-8 字节而不是字符数计算 16 KB 单消息限制，并给出按扩展字形安全切分的分段预览。
4. **发送前安全检查**：检查私钥/助记词、访问令牌、密码赋值、邮箱与电话号码；结果只显示类型与处置建议，不回显秘密。
5. **安全回填**：空内容、超限内容及严重秘密命中时禁止回填；其余内容也只回填编辑框，永不自动发送。
6. **视觉层次**：概览指标、模板卡片、样式切换、安全状态和分段预览使用现有 Veil 主题语义，兼容深浅色与动态字体。

## 快速清空聊天记录

1. **列表右滑入口**：无需先进入会话，右滑即可选择“清空”。
2. **长按入口**：会话上下文菜单同步提供“清空本地聊天记录”。
3. **防误触**：破坏性右滑关闭全滑执行，点击后仍需二次确认。
4. **边界清晰**：确认文案明确只删除本机消息和附件，保留联系人、信任关系，并且不影响对方设备。
5. **复用成熟路径**：调用现有 `clearConversationLocally`，沿用附件接收中阻断、入站 tombstone、附件文件删除、未读归零和会话列表刷新逻辑。

## 隐私与兼容

- 正文只在本机内存中分析；关闭工作台后不持久化分析结果。
- 锻造台内容同样只在内存中处理，不写入日志、剪贴板或分析数据库。
- 不上传、不同步、不调用互联网 AI。
- 不新增数据库表、消息字段或 wire packet；对方无需升级。
- 游戏和兵棋协议消息在进入统计前过滤，避免内部控制包污染结果。
- 引用回复只分析新回复，不把被引用的旧内容重复当成行动项。
- 诊断只记录数量，不记录正文、链接或附件内容。

## 性能

- 数据库完整历史读取、分类和链接识别均在后台队列执行。
- UI 只接收结构化快照，列表按需渲染。
- 使用现有 `messageReloadGeneration` 丢弃过期加载；被其他刷新抢占时恢复 loading 状态，避免按钮永久卡住。
- 正常聊天仍保持设备分级的窗口分页，不因工作台永久扩大渲染负担。
- 锻造台为线性文本处理；分段以 Swift `Character` 为单位，避免拆开 emoji 组合字形。

## 验收标准

- 工作台能正确分类中英文行动项、问题、链接、图片和语音；
- 游戏协议包不出现在计数和条目中；
- 点击条目能回到完整历史中的原消息；
- 新消息到达时工作台可刷新；
- iPhone 7 上分析 10,000 条短消息不阻塞主线程；
- 不产生新的明文持久化和网络请求。
- 五类模板和四种样式均可预览，16 KB 限制按 UTF-8 正确计算；
- 关键秘密被阻断且不回显，普通隐私信息给出清晰提醒；
- 回填只更新草稿，不触发发送。
- 会话列表右滑和长按均可唤起清空确认，取消不产生变化；确认后列表预览与未读状态立即刷新；
- 正在接收附件时安全拒绝清空并显示既有错误，不留下半删除状态。
