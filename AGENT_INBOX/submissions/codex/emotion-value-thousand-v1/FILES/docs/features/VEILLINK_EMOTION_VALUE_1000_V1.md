## Runtime acceptance contract

- `VeilEmotionGardenEngine.rituals.count == 1000`，ID 为连续的 `EV-0001...EV-1000`。
- 每个 ID 的提示文本、三步操作组合及完成回响均唯一；每种状态有 100 项，每个“状态 + 场景”组合有 10 项且覆盖全部互动类型。
- 用户可通过两个选择器或全库 ID/关键词搜索到达全部 1000 项；每项都能逐步勾选、启动秒级倒计时、暂停/继续、重置并确认完成。每日三步只从当前状态与场景的 10 项中选择，不隐藏其他条目。
- 所有条目离线运行、可跳过、不自动发送、不读取聊天、不上传状态，也不宣称诊断或治疗。
- 状态/场景、稳定 ID 和搜索文本均预建索引；搜索结果限制 50 项，计时器只在运行状态存在，暂停或退出立即释放。
- `CANDIDATE-SOURCE` 表示完整源码已放入本提案，不表示已合并、已构建、已真机验证或已发布。
