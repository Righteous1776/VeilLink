# RISKS — file-integrity-lab-v1

## 风险与缓解

1. **iCloud 文件尚未落地**：系统文件提供器可能延迟下载；读取失败会显示稳定错误，用户可待下载完成后重试。集成时需用 iCloud Drive 真机验证。
2. **超大文件耗电/耗时**：实现为 512 KiB 流式读取，内存有界且每块检查取消；仍会产生与文件大小成正比的 I/O 与 SHA-256 CPU 开销。页面不宣称测速。
3. **读取期间文件变化**：结果代表本次实际读取流。工具不锁定或修改源文件；对于正在被其他 App 写入的文件，用户应在写入完成后重新校验。
4. **哈希结论措辞**：一致结论基于字节数和 SHA-256，不是逐字节二次读取。SHA-256 适合完整性核验，但页面不把它描述为数字签名或来源认证。
5. **文件名进入剪贴板**：报告仅包含用户选择的文件名、字节数和摘要，不含绝对路径；剪贴板设为本机限定并 5 分钟过期。用户仍应自行判断文件名是否敏感。
