# Risks

- This is a mandatory gate. Validation must remain fail-closed and must not auto-fill, relax or bypass the exact acknowledgment.
- The deferred closure must run only once per tap; the `signing` guard prevents duplicate evidence records.
- The final UIKit text is published only when editing ends, after marked composition is committed. Intermediate marked pinyin remains excluded.
- Agreement text, SHA-256, document version, keychain MAC and release/build re-signing rules are untouched.
- A simulator cannot fully represent every third-party IME; physical iPhone 7 and current-device testing remains required before release.
