## 90 项功能清单（每项均有独立产品体验和工程核心）

### A. 互动叙事宇宙（E01-E10）

**工程策略：** 本地确定性剧情状态机、可验证剧本、脱离网络的多结局；双人协作在稳定后接入

- **E01 世界级分支叙事引擎** · **首批可运行候选内核**：跨章节影响后续剧情，支线汇入不同结局。工程核心：条件图、物品与标记、存档回放。
- **E02 持续演化的 NPC 人物关系**：NPC 对玩家先前选择形成可信反馈。工程核心：关系状态与长期事件摘要。
- **E03 角色记忆与手写日记宇宙**：事件自动汇编角色视角回忆录。工程核心：本地时序事件簿与隐私分区。
- **E04 大型章节剧本制作器**：自己制作城市、人物、场景与对话。工程核心：可视化 DAG 编辑器与静态校验。
- **E05 多结局悬疑推理长篇**：调查、证物、证词和线索形成分支。工程核心：线索依赖图与案件一致性求解。
- **E06 导演剪辑式剧情回溯**：跨时点查看不同决策如何改变故事。工程核心：确定性事件重放与支线比较。
- **E07 角色配音对话导演**：每个角色可有不同语速、字幕与舞台效果。工程核心：本地 TTS 适配与脚本时间线。
- **E08 双人接力剧本共创**：两台设备轮流推进一个共同世界。工程核心：冲突可视化与加密事件同步（后期）。
- **E09 规则驱动无限支线**：根据世界种子拼装大量可玩支线而非随机文字。工程核心：约束模板、事件图与种子系统。
- **E10 异步互动剧场**：离线时先写剧情选择，碰面后可安全继续。工程核心：只读候选事件队列与版本冲突模型。

### B. 大型单人游戏世界（E11-E20）

**工程策略：** 与现有象棋/五子棋/兵棋/光轨/节奏/平台跳跃明确区分，独立游戏内核

- **E11 程序化地牢 Roguelite**：种子地图、构筑选择、遗物组合与章节 Boss。工程核心：回合战斗内核和关卡生成器。
- **E12 大型塔防世界**：多地图防线、技能树与地形策略。工程核心：单位寻路、波次与低功耗渲染。
- **E13 微缩未来城市经营**：建设交通、能源、就业与公共服务。工程核心：资源网络与因果驱动市民模拟。
- **E14 海岛生态经营**：农场、海洋生态、季节与栖息地修复。工程核心：生态网格和可逆建造记录。
- **E15 太空殖民基地模拟**：维持氧气、温度、材料与殖民地生产链。工程核心：资源生产 DAG 与设施热模型。
- **E16 精密赛车改装车库**：调校悬挂、动力、轮胎并测试赛道。工程核心：固定时间步车辆模型（非光轨竞速）。
- **E17 都市地铁调度王国**：设计地铁线路和完整时刻表防止拥堵。工程核心：离散事件调度与客流仿真。
- **E18 深海潜艇生存探索**：用声呐、航线与维修探索未知海域。工程核心：2D 声学迷雾与艇体系统。
- **E19 开放场景侦探事务所**：在城市街区中自由走访取证解案。工程核心：证据图谱和可检验推断。
- **E20 模块化沙盒建造**：自由拼装建筑、机关与互动装置。工程核心：网格几何、碰撞和安全蓝图。

- **E22 同屏双人合作机关城**：两人同机配合机关操作和线索交互。工程核心：双人触摸捕获与独立控制区。

## 验收原则

1. 每个体验必须具备独立 `FeatureID`、用户可验证的端到端旅程、边界、回放/存档和崩溃隔离策略。
2. 不准把空壳按钮、只展示名称的 UI 或简单参数开关算成完成的“大型功能”。
3. iOS 15.8.3 / iPhone 7 为最低支持目标；先提供 30fps 轻量级降级，再考虑视觉提升；避免全屏 `DragGesture` 覆盖点击。
4. BLE 多人需要明确双方同意、E2EE、不劫持聊天会话、不修改既有 Wire v4 和 SQLite v10；本次阶段内一概不触碰。
