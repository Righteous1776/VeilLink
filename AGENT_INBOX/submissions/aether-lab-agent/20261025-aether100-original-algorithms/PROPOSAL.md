# AetherLab 100 — 工程提案

**交付边界：** 100 个编号 AETH-201 至 AETH-300 的独立算法分支，10 个领域各 10 项，具备手动去标识化 JSON 输入、中文输出和 SwiftUI 入口。这是离线算法实验室，不是 100 个实时设备集成、蓝牙服务或小游戏整机系统。

在 R1 采取原创 Swift/Foundation 实现，不复制第三方代码、素材或数据库内容。十一项开源候选登记在 OSS_REUSE_REGISTRY.md，实际依赖引入必须下一次由 Governor 固定版本、审查许可、构建并保留 NOTICE。

为何避免直接「照搬」：即使仓库标注 MIT/Apache/BSD，也需保留著作权与许可证；有些代码只适合 Android、较新 Swift、宏或高性能设备，直接加入现有 Build61 会造成编译失败或运行故障。

**源代码结构：** Core 3 个 Swift 文件：输入校验、目录/共同算法、10 个完整领域开关，共 100 项真实计算。UI 1 个 SwiftUI 页面：100 项检索、编号选择、样本 JSON 输入、运算输出、归档前警告。XCTest 1 个文件：编号去重、100/100 样本、极端输入、图论/数据/CRC/空间/游戏等测试。

**保护面：** 零 SQLite v10、Keychain、Wire v4、BLE/LAN 真实通道、A9/A10 权限、真实聊天室、旧版本回滚、后台保活、版本号、IPA 签名改动。

**Owner 意图：** 增加百项强大稀有功能；当前可验证的工程交付是 100 项可执行原生算法。若要进一步达到成熟大型产品级体验，未来要分别加实时数据接入、独立交互页面、可验证开源扩展，并迭代性能和 UI。
