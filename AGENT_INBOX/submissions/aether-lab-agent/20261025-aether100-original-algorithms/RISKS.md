# 风险、权属与治理

- **实验级**：100 个可执行计算≠100 个成熟运行时大型功能；严禁称为已合并/已在手机可用。图论/隐私/加密相关计算不承诺安全、身份真实性或实际无线物理性能。
- **权限隔离**：所有输入来自手工 JSON，无系统定位、私钥、消息明文、真实日志或远端网络；未取得监听/路由/数据库权限；不改变真实设备状态。
- **算法局限**：局部近似（例如 LOS、A*、RDP、P95）只对输入样本成立。CRC32 不是抗篡改加密认证；PageRank 不是受信任节点识别。
- **内存限制**：统一 32 KiB 输入、最多 256 数字/边、32x32 网格、有限字符串与点；真实 iPhone 7 主线程性能未验证。
- **第三方许可**：候选 MIT/Apache/BSD/Swift-exception，仅作为审查目录；第三方数据集可能是 CC-BY、ODbL、专有授权，不能只因源码开源就复制其数据。
- **主线冲突**：#64–#66 为 P0 稳定性；#67/#68、#70、#69/#72 同样可能在 `ToolCenterView.swift` 增加入口，必须由 Governor 人工仲裁。
- **运行时隔离**：禁止直接修改 SQLite v10、Keychain、Wire v4、A9/A10、签名、SDK 最低版本、GitHub Actions、发版；不可绕过 iOS15 后台规则。
- **未来扩展**：每次仅选择小批经授权的 OSS 固定提交版本；先做许可、SBOM、尺寸预算、Xcode、XCTest、真机门禁。
